Quick Start
  1. Install Promptfoo: npm install -g promptfoo
  2. Copy a config block above, replace <EC2-IP>, save as promptfooconfig.yaml
  3. Initialise the red team dataset: promptfoo redteam generate
  4. Run the attack: promptfoo redteam run
  5. View results: promptfoo view
  6. Add new Beelzebub personas via the Beelzebub page — this page refreshes automatically when new service YAML files are added.
